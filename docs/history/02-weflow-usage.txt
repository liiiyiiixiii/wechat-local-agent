本地微信读取 — 2026-10-16

打开和使用
双击 launch-real/启动WeFlow.command，保持原版微信登录并同步消息。
在“聊天”中选择联系人，查看文字、图片和已下载附件。
“资源浏览 → 图片”支持本地图片解密和预览。缓存仅保存在本工作区 private/weflow-ui/media-cache/。
点击聊天中的普通文档会调用系统关联应用；压缩包和其他文件在访达中定位，不自动执行。
附件尚未下载时，请先用原版微信下载，再回到 WeFlow 点击。

本机 Agent 命令
以下命令返回 JSON，不发送微信消息，也不建立网络服务：
  ./读取微信.command verify
  ./读取微信.command resolve '联系人或群名称'
  ./读取微信.command read --chat-id '具体微信用户名或群 ID' --limit 20
  ./读取媒体.command files
  ./读取媒体.command file '附件原文件名' [精确字节数]
  ./读取媒体.command images
files 列出已下载附件；file 唯一匹配附件并返回真实路径，重名不猜测。
images 列出已经由 WeFlow 解密的图片路径；需要的图片尚未在缓存时，先在 WeFlow 打开它。
Agent 可用自己的图片查看或文档读取工具读取返回路径。只在本人授权的任务中调用。
读取微信.command 另有 init/check/watch 增量命令，可运行 --help 查看参数。
